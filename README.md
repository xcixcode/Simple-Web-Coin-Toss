# Simple-Web-Coin-Toss

**사용자가 직접 파워를 조절하여 던지는 재미를 느낄 수 있도록 제작한 인터랙티브 웹 동전 던지기**

외부 리소스(이미지, 사운드 파일) 없이 순수 웹 기술(Vanilla JS)로만 구현되어 가볍고 빠르게 작동하는 3D 동전 던지기 시뮬레이터입니다.  
사용자가 버튼을 누르는 시간에 따라 파워가 결정되며, 정밀한 사운드 합성 로직과 CSS 3D 시퀀스를 통해 몰입감 있는 사용자 경험을 제공합니다.

---

## 개요

**Simple-Web-Coin-Toss** 프로젝트는 브라우저 내에서 물리적인 상호작용과 소리를 얼마나 정교하게 구현할 수 있는지 탐구한 프로젝트입니다.  
`requestAnimationFrame` 루프에서 동전의 위치와 회전을 프레임마다 계산하여 도약, 체공, 낙하, 착지 후 바운스까지 하나의 흐름으로 제어하며, 동전의 두께를 포함한 모든 시각적 요소와 소리는 코드를 통해 실시간으로 생성됩니다. 단일 파일 구조로 설계되어 별도의 서버나 라이브러리 없이도 완벽한 기능을 보장합니다.

---

## 기술 스택

- **HTML5 / CSS3** - `perspective`와 `preserve-3d`를 활용한 3D 가상 공간, 얇은 원판을 쌓아 만든 입체 동전(앞/뒷면 + 두께 있는 옆면) 구조 설계, 시스템 라이트/다크 테마 대응  
- **JavaScript (Vanilla JS)** - 비즈니스 로직 제어, Pointer Events 기반 입력 처리 및 `requestAnimationFrame`을 이용한 실시간 파워 게이지 시스템 구축  
- **Web Audio API** - `OscillatorNode`와 `GainNode`를 제어하여 'toss(휘두르는 소리)', 'drop(금속 타격음)', 'tap(바운스 타격음)' 사운드 합성  
- **CSS 3D Transform** - 프레임마다 계산한 위치·회전값을 `transform`에 적용하여 포물선 비행, 바운스, 잔떨림 등 물리적인 움직임 구현

## 주요 기능

- **인터랙티브 파워 게이지**: 마우스·터치·키보드(Space / Enter)로 버튼을 누르고 있는 시간에 따라 0~100 사이를 왕복하는 동적 게이지 시스템 (16ms당 3.8단위 가중치를 프레임 속도와 무관하게 적용)
- **정밀한 사운드 동기화**: 
    - **Toss**: 300Hz에서 1200Hz로 급격히 상승하는 주파수를 통해 공기를 가르는 소리 구현
    - **Drop**: 800Hz, 1100Hz, 1500Hz의 다중 주파수 합성에 짧은 잔향을 더해 실감 나는 금속성 충돌음 구현
    - **Tap**: 착지 후 동전이 튕길 때마다 작은 타격음 재생
- **입체 동전**:
    - 얇은 원판 16장을 쌓아 두께와 톱니(리브) 옆면을 만들고, 앞면 쪽은 금색·뒷면 쪽은 은색으로 표현
    - 회전각에 따라 흐르는 금속 반사광, 정지 상태에서 카메라 쪽으로 22° 기울어진 구도
    - 앞/뒷면 SVG 도안은 수정 없이 원본 그대로 사용
- **3D 던지기 애니메이션 시퀀스**:
    - **상승 단계**(1.0초): 정점이 평평한 포물선 궤적으로 올라가며, 올라갈수록 카메라에 가까워지는 원근감과 축이 비틀리며 구르는 입체적 회전 연출
    - **낙하 단계**(0.7초): 낙하 구간에서 나머지 절반의 회전을 마무리하며, 지면에 닿는 순간 정확한 사운드 피드백 제공
    - **착지 단계**(0.4초): 작아지며 여러 번 튕기고 흔들리다가 눕는 바운스와 잔떨림 연출, 그림자는 높이에 따라 크기와 농도가 변화
    - **회전수**: `4 + 파워÷15(내림)`바퀴 (뒷면이면 반 바퀴 추가)
- **시각적 UX 장치**: 결과 도출 전 `filter: blur(25px)`를 적용한 **프라이버시 블러** 모드로 긴장감 조성 (착지 0.1초 후 해제, 0.4초 후 결과 표시)
- **기록 및 설정**: 태양/초승달 누적 횟수를 `localStorage`에 저장하고, 우측 상단의 🔊/🔇(소리 켜기·끄기), 🗑️(기록 초기화) 버튼 제공
- **접근성**: 결과 문구를 스크린리더가 읽어 주고(`role="status"`), 키보드 포커스 표시를 제공하며, 시스템의 '모션 줄이기' 설정을 따름
- **반응형 아케이드 UI**: `viewport-fit=cover`와 `dvh` 단위를 사용하여 모바일 상단 바와 노치를 고려한 풀스크린 레이아웃 제공

## 안내 및 참고사항

본 프로젝트는 개인 학습 및 포트폴리오 용도로 제작되었습니다.

> ⚠️ 참고
>
> - **사운드 재생 정책**: 현대 브라우저의 자동 재생 방지 정책으로 인해, `AudioContext`는 첫 번째 "동전 던지기" 입력 시점에 생성·활성화되며 그 전에는 소리가 출력되지 않습니다.
> - **성능 최적화**: 동전의 이동과 회전은 GPU 가속을 활용하는 `transform` 속성으로 처리하고, 애니메이션은 `requestAnimationFrame`에 맞춰 갱신합니다. 다만 프라이버시 블러에 쓰이는 `filter: blur`는 저사양 기기에서 부하가 있을 수 있습니다.
> - **디자인 소스**: 동전 내 아이콘은 SVG를 직접 내장하여 확대/축소 시에도 깨짐 없는 화질을 유지합니다.
> - **데이터 저장**: 누적 기록과 소리 설정은 사용자의 브라우저(`localStorage`)에만 저장되며 외부로 전송되지 않습니다.
